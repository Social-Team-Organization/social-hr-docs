# الوحدات

![منظومة وحدات الموارد البشرية — سجل الموظف في المركز، ووحدات لكل مرحلة من دورة حياة الموظف](../../product/assets/modules-ecosystem.png)

تنظّم Social HR قدرات الموارد البشرية في **[وحدات](./PLATFORM.md)** — مناطق مستقلة في المنتج تظهر في شريط التنقل الجانبي عندما تكون مُستحقّة ضمن [باقة](./PLANS.md) العميل.

كل وحدة أدناه موصوفة كـ **صفحة منتج مصغّرة**: الغرض، القدرات، من يستخدمها، سير العمل المعتاد، الفوائد، والقيود.

لمعرفة [توفر الوحدات حسب الباقة](./PLANS.md#full-module-catalog)، راجع الباقات. ولمعرفة كيفية ترابط الوحدات، راجع [كيف يعمل النظام](./HOW_IT_WORKS.md).

> **نظرة سريعة**
>
> | الفئة | الوحدات |
> |-------|---------|
> | **دورة الحياة** | Recruitment → Onboarding → Employees → Offboarding |
> | **الوقت والأجر** | Attendance، Leave، Payroll |
> | **التطوير** | Performance (PMS) |
> | **العمليات** | Assets، Helpdesk، Projects، Documents |
> | **امتدادات Social HR** | Geofencing، Face Check-In، Activity Tracking، Biometric Devices |

## وحدات الموارد البشرية الأساسية

### Employees

![خيارات تسجيل حضور الموظف تغذي وحدة Attendance](../../product/assets/attendance-checkin.png)

**الغرض:** دليل الموظفين المركزي — **المركز** لكل سجل موظف في المؤسسة. تتصل بها معظم [الوحدات](./HOW_IT_WORKS.md#the-employee-record-as-hub) الأخرى.

> **نظرة سريعة:** الدليل · الهيكل التنظيمي · الورديات · أنواع العمل · طلبات المستندات

| | |
|---|---|
| **من يستخدمها** | الجميع — الموارد البشرية تحافظ على السجلات؛ المديرون يعرضون الفرق؛ الموظفون يحدّثون ملفاتهم |
| **سير العمل المعتاد** | الموارد البشرية تنشئ الموظف → تُعيّن القسم و[نوع العمل](./FEATURES.md#geofencing-and-work-type-location-policies) والوردية → تبدأ الخدمة الذاتية للموظف |
| **تعتمد على** | إعدادات المؤسسة (الأقسام، أنواع العمل، الورديات) في إعدادات النظام |

**القدرات الرئيسية:**

- ملفات الموظفين بالمعلومات الشخصية والعملية والبنكية والمستندات
- الهيكل التنظيمي وبنية الأقسام
- تعيين الورديات و[أنواع العمل](./FEATURES.md#geofencing-and-work-type-location-policies)، بما في ذلك الجداول المتناوبة
- طلبات الورديات و[طلبات نوع العمل](./FEATURES.md#geofencing-and-work-type-location-policies) (تغييرات مؤقتة في الجدول)
- الإجراءات التأديبية وتوزيع مستندات السياسات
- طلبات المستندات من الموارد البشرية إلى الموظفين

**الفوائد:** مصدر واحد موثوق لبيانات الموظفين؛ نقطة ارتكاز للحضور والانصراف والإجازات والرواتب والأداء.

**القيود:** مساحة عمل واحدة = مؤسسة واحدة — لا يوجد مبدّل شركات ([قرارات التصميم](./DESIGN_DECISIONS.md#no-company-switcher)).

**توفر الباقة:** All plans.

---

### Recruitment

![مسار التوظيف يتدفق إلى Onboarding وسجلات Employees](../../product/assets/recruitment-onboarding.png)

**الغرض:** إدارة مسار التوظيف من فتح الوظيفة إلى تعيين المرشح.

> **نظرة سريعة:** مراحل المسار · kanban · المقابلات · الاستبيانات · التعيين → Onboarding

| | |
|---|---|
| **من يستخدمها** | [مسؤولو التوظيف](./ROLES_AND_PERMISSIONS.md#recruiter)، مديرو التوظيف، مسؤولو الموارد البشرية |
| **سير العمل المعتاد** | إنشاء حملة → إضافة مرشحين → الانتقال بين المراحل → التعيين → [Onboarding](./MODULES.md#onboarding) |
| **يتصل بـ** | [Onboarding](./MODULES.md#onboarding)، [Employees](./MODULES.md#employees) |

**القدرات الرئيسية:**

- حملات توظيف بمراحل مسار قابلة للتخصيص
- سجلات المرشحين وعرض kanban للمسار
- جدولة المقابلات وتتبع النتائج
- استبيانات التوظيف وتقييمات مجمع المهارات
- إعلانات الوظائف المفتوحة (مع تكامل خارجي اختياري)
- تحويل المرشحين المعيّنين إلى Onboarding

**الفوائد:** توظيف منظم مع تحليلات لوحة المعلومات؛ مسار سلس إلى سجل الموظف.

**القيود:** Standard و Enterprise فقط (وليس Trial الافتراضي). تكاملات لوحات الوظائف الخارجية تعتمد على الإعداد.

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

---

### Onboarding

**الغرض:** لوحات مهام منظمة للموظفين الجدد بعد التوظيف.

> **نظرة سريعة:** قوائم مهام · مهام الموارد البشرية/تقنية المعلومات/الموظف الجديد · تتبع التقدم

| | |
|---|---|
| **من يستخدمها** | مسؤولو الموارد البشرية، الموظفون الجدد، منسقو الأقسام |
| **سير العمل المعتاد** | وصول المرشح المعيّن → تُعيَّن مهام للموارد البشرية وتقنية المعلومات والموظف → الإكمال ينشئ سجل الموظف |
| **يتصل بـ** | [Recruitment](./MODULES.md#recruitment)، [Employees](./MODULES.md#employees) |

**القدرات الرئيسية:**

- عروض التهيئة مرتبطة بالمرشحين المعيّنين
- قوائم مهام للموارد البشرية وتقنية المعلومات والموظف الجديد
- تتبع التقدم حتى اكتمال سجل الموظف

**الفوائد:** لا شيء يُغفَل أثناء إعداد الموظف الجديد؛ لوحة المعلومات تعرض تقدم التهيئة.

**القيود:** Standard و Enterprise فقط.

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

### Attendance

![طرق متعددة لتسجيل الحضور — الويب، الجوال، التحقق بالوجه — كلها تغذي سجلات الحضور والانصراف](../../product/assets/attendance-checkin.png)

**الغرض:** تسجيل أوقات عمل الموظفين — **المصدر المعتمد لـ [ساعات الأجر](./MODULES.md#attendance)**.

> **نظرة سريعة:** تسجيل الحضور/الانصراف · التحقق · سجلات العمل · العمل الإضافي · تقييد IP

| | |
|---|---|
| **من يستخدمها** | جميع الموظفين يسجلون الحضور؛ المديرون يتحققون؛ الموارد البشرية تُعدّ؛ الرواتب تعتمد على السجلات |
| **سير العمل المعتاد** | تسجيل الحضور → تطبيق السياسات → تسجيل الانصراف → تحقق المدير → الرواتب |
| **يتصل بـ** | [Geofencing](./MODULES.md#geofencing)، [Face Check-In](./MODULES.md#face-check-in)، [Activity Tracking](./MODULES.md#activity-tracking)، [Payroll](./MODULES.md#payroll) |

**القدرات الرئيسية:**

- تسجيل الحضور والانصراف من شريط التنقل أو شاشات الحضور والانصراف
- سجلات الحضور والانصراف والطلبات (التصحيحات) وتحقق المدير
- [سجلات العمل](./MODULES.md#attendance) — مصفوفة يومية تستخدمها الرواتب
- [حساب الساعات](./MODULES.md#attendance) لتتبع العمل الإضافي
- تتبع التأخر والانصراف المبكر
- تقييد IP اختياري لمواقع تسجيل الحضور
- التكامل مع Geofencing و Face Check-In وأجهزة البصمة ومراقبة النشاط

**الفوائد:** مصدر أجر واحد؛ طرق متعددة لتسجيل الحضور؛ سير عمل لطلبات التصحيح.

**القيود:** [وقت الخمول في النشاط](./FEATURES.md#activity-tracking-desktop-monitoring) لا يُخفّض الساعات تلقائياً. [سجلات وقت المشاريع](./MODULES.md#projects) منفصلة.

تفاصيل إضافية: [الميزات — Attendance](./FEATURES.md#attendance-and-check-in). السياسة: [سياسات الحضور والانصراف](./POLICIES.md#attendance).

**توفر الباقة:** All plans.

### Leave

![سير عمل الموافقة على طلب الإجازة — الموظف يقدّم، المدير يوافق، الرصيد يُحدَّث](../../product/assets/leave-workflow.png)

**الغرض:** إدارة الإجازات — الأنواع، الأرصدة، الطلبات، والموافقات.

> **نظرة سريعة:** أنواع الإجازات · الأرصدة · سير الموافقة · العطل الرسمية · الإجازة التعويضية

| | |
|---|---|
| **من يستخدمها** | الموظفون يقدّمون الطلبات؛ المديرون يوافقون؛ الموارد البشرية تُعدّ الأنواع والأرصدة |
| **سير العمل المعتاد** | الطلب → الموافقة → خصم الرصيد → ينعكس في الحضور والانصراف والرواتب |
| **يتصل بـ** | [Attendance](./MODULES.md#attendance)، [Payroll](./MODULES.md#payroll) |

**القدرات الرئيسية:**

- أنواع الإجازات (سنوية، مرضية، بدون أجر، وغيرها) بقواعد قابلة للتخصيص
- أرصدة الإجازات وطلبات التخصيص
- سير عمل طلب الإجازة مع موافقة المدير
- الإجازة التعويضية مرتبطة بالعمل الإضافي (عند التفعيل)
- تحليلات لوحة المعلومات وعروض «من في إجازة اليوم»
- التكامل مع العطل الرسمية وأنماط الإجازات على مستوى المؤسسة

**الفوائد:** سلاسل موافقة قابلة للتخصيص؛ رؤية عبر لوحة المعلومات؛ تغذي حسابات الرواتب.

**القيود:** قواعد تقييد الإجازات قد تحظر التقديم — يجب على الموارد البشرية الإعداد بعناية.

تفاصيل إضافية: [الميزات — إدارة الإجازات](./FEATURES.md#leave-management). السياسة: [سياسات الإجازات](./POLICIES.md#leave).

**توفر الباقة:** All plans.

### Payroll

![التحقق من الحضور والانصراف يتدفق إلى سجلات العمل وإنشاء قسائم الراتب](../../product/assets/payroll-cycle.png)

**الغرض:** معالجة تعويضات الموظفين — العقود، قسائم الراتب، والمدفوعات ذات الصلة.

> **نظرة سريعة:** العقود · قسائم الراتب · البدلات · الخصومات · المصروفات والاسترداد

| | |
|---|---|
| **من يستخدمها** | [أخصائيو الرواتب](./ROLES_AND_PERMISSIONS.md#payroll-specialist)، مسؤولو الموارد البشرية، الموظفون (عرض قسائم راتبهم) |
| **سير العمل المعتاد** | إعداد العقد → حضور وانصراف مُتحقّق منه → إنشاء قسيمة الراتب → وصول الموظف |
| **تعتمد على** | سجلات [Attendance](./MODULES.md#attendance) و[Leave](./MODULES.md#leave) المُتحقّق منها |

**القدرات الرئيسية:**

- عقود التوظيف بهياكل الرواتب
- البدلات والخصومات
- إنشاء قسائم الراتب (يدوي أو مجدول)
- القروض والسلف وصرف الإجازات والمصروفات
- إعداد الضريبة الاتحادية

**الفوائد:** متكامل مع الحضور والانصراف والإجازات — لا إدخال مزدوج للبيانات.

**القيود:** يتطلب حضوراً وانصرافاً مُتحقّقاً منهما؛ لا يوجد تكامل محاسبي خارجي قياسي موثّق.

تفاصيل إضافية: [الميزات — Payroll](./FEATURES.md#payroll). السياسة: [سياسات الرواتب](./POLICIES.md#payroll).

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

### Performance (PMS)

**الغرض:** الأهداف، التقييم، ودورات إدارة الأداء.

> **نظرة سريعة:** OKRs · تقييم 360 درجة · فترات المراجعة · نقاط المكافأة

| | |
|---|---|
| **من يستخدمها** | الموظفون يضعون الأهداف؛ المديرون يراجعون؛ الموارد البشرية تُعدّ الدورات |
| **سير العمل المعتاد** | الموارد البشرية تفتح فترة مراجعة → الموظفون يضعون OKRs → جمع التقييم → مراجعة المدير |

**القدرات الرئيسية:**

- الأهداف والنتائج الرئيسية (OKRs)
- دورات تقييم 360 درجة مع قوالب أسئلة
- اجتماعات الأداء وفترات المراجعة
- سجل نقاط المكافأة

**الفوائد:** ثقافة أداء منظمة؛ مخططات لوحة المعلومات لحالة الأهداف.

**القيود:** Standard و Enterprise فقط.

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

---

### Offboarding

**الغرض:** عمليات خروج منظمة للموظفين.

> **نظرة سريعة:** مراحل الخروج · خطابات الاستقالة · تنسيق إرجاع الأصول

| | |
|---|---|
| **من يستخدمها** | مسؤولو الموارد البشرية، الموظفون المغادرون، تقنية المعلومات |
| **سير العمل المعتاد** | الاستقالة → قائمة خروج → إرجاع الأصول → إلغاء التفعيل |

**القدرات الرئيسية:**

- مراحل عملية إنهاء الخدمة وقوائم التحقق
- إدارة خطابات الاستقالة
- التنسيق مع إرجاع [Assets](./MODULES.md#assets)

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

## وحدات العمليات

### Assets

**الغرض:** تتبع معدات المؤسسة — الحاسبات المحمولة، الهواتف، الأثاث، وغيرها من المخزون.

| | |
|---|---|
| **من يستخدمها** | مسؤولو الموارد البشرية وتقنية المعلومات؛ الموظفون يطلبون المعدات |
| **سير العمل المعتاد** | الفهرس → طلب الموظف → التخصيص → الإرجاع عند Offboarding |

**القدرات الرئيسية:** فهرس الأصول، الطلبات، سجل التخصيص، معالجة الإرجاع.

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

---

### Helpdesk

**الغرض:** الدعم الداخلي — الموظفون يرفعون تذاكر، والموارد البشرية وتقنية المعلومات ترد.

| | |
|---|---|
| **من يستخدمها** | جميع الموظفين ينشئون تذاكر؛ الموارد البشرية وتقنية المعلومات والمديرون يحلّون |
| **سير العمل المعتاد** | الموظف ينشئ تذكرة → توجيه حسب القسم → حل مع دعم الأسئلة الشائعة |

**القدرات الرئيسية:** أنواع التذاكر، الوسوم، الأولويات، التوجيه حسب القسم، قاعدة معرفة الأسئلة الشائعة.

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

---

### Projects

**الغرض:** تسليم المشاريع وتسجيل الوقت — **منفصل عن ساعات الحضور والانصراف للرواتب**.

> **مهم:** الساعات المسجّلة في سجلات وقت المشاريع **لتتبع المشاريع فقط**. **لا** تحل محل [Attendance](./MODULES.md#attendance) أو [Payroll](./MODULES.md#payroll) ولا تغذيهما. راجع [قرارات التصميم — وقت المشروع منفصل](./DESIGN_DECISIONS.md#project-time-separate-from-attendance-time).

| | |
|---|---|
| **من يستخدمها** | مديرو المشاريع، أعضاء الفريق، قادة الأقسام |
| **سير العمل المعتاد** | إنشاء مشروع → تعيين مهام → تسجيل ساعات سجل الوقت → تتبع التقدم |

**القدرات الرئيسية:** مراحل kanban، المهام، سجلات الوقت، أدوار مدير المشروع.

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

---

### Documents

**الغرض:** إدارة مستندات الموظفين بما يتجاوز مرفقات الملف الشخصي.

| | |
|---|---|
| **من يستخدمها** | مسؤولو الموارد البشرية، الموظفون الذين يستوفون طلبات المستندات |
| **سير العمل المعتاد** | الموارد البشرية تطلب مستنداً → الموظف يرفع → الموارد البشرية تتتبع الإكمال |

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

## وحدات امتداد Social HR

توسّع هذه الوحدات الحضور والانصراف ورؤية القوى العاملة إلى ما يتجاوز قدرات الموارد البشرية القياسية.

### Geofencing

![حد السياج الجغرافي للمكتب مقابل نوع العمل عن بُعد — قواعد الموقع عند تسجيل الحضور](../../product/assets/geofencing.png)

**الغرض:** فرض [سياسات الموقع](./FEATURES.md#geofencing-and-work-type-location-policies) عند تسجيل حضور الموظفين، بناءً على [نوع العمل](./FEATURES.md#geofencing-and-work-type-location-policies) لديهم.

> **نظرة سريعة:** دائرة المكتب · سياسات نوع العمل · سجل التدقيق · تجاوز لكل موظف

| | |
|---|---|
| **من يستخدمها** | مسؤولو الموارد البشرية يُعدّون؛ الموظفون يختبرون عند تسجيل الحضور؛ المديرون يرون سجلات التدقيق |
| **سير العمل المعتاد** | الموارد البشرية تضبط الإحداثيات → تُعيّن أنواع العمل → يُقيَّم تسجيل حضور الموظف مقابل السياسة |
| **يتطلب** | [باقة Enterprise](./PLANS.md#enterprise) (أو تجاوز) **و** تفعيل مسؤول الموارد البشرية |

**القدرات الرئيسية:**

- دائرة [السياج الجغرافي](./FEATURES.md#geofencing-and-work-type-location-policies) للمكتب (خط العرض، خط الطول، نصف القطر)
- [سياسة الموقع](./FEATURES.md#geofencing-and-work-type-location-policies) لكل نوع عمل: يتطلب التواجد داخل السياج، السماح من أي مكان، أو حظر تسجيل الحضور
- سجل تدقيق لكل تقييم موقع
- [تجاوز السياج الجغرافي](./FEATURES.md#geofencing-and-work-type-location-policies) لكل موظف للاستثناءات

**الفوائد:** قواعد هجينة مرنة؛ تجاوزات مؤقتة عبر [طلبات نوع العمل](./FEATURES.md#geofencing-and-work-type-location-policies)؛ مسار تدقيق كامل.

**القيود:** يتحكم بتسجيل الحضور فقط — لا يحسب الأجر. يتطلب إذن موقع الجهاز.

تفاصيل إضافية: [الميزات — Geofencing](./FEATURES.md#geofencing-and-work-type-location-policies). السياسة: [سياسات Geofencing والموقع](./POLICIES.md#geofencing-and-location).

**توفر الباقة:** [Enterprise](./PLANS.md#enterprise) (افتراضي).

### Face Check-In

![سير تسجيل التعرف على الوجه والتحقق — التسجيل مرة واحدة، التحقق عند كل تسجيل حضور](../../product/assets/face-checkin.png)

**الغرض:** التحقق الاختياري من الهوية عبر كاميرا الويب قبل تسجيل الحضور والانصراف.

> **نظرة سريعة:** تسجيل التعرف على الوجه · التحقق المباشر · إعادة التسجيل · قوالب خصوصية

| | |
|---|---|
| **من يستخدمها** | الموظفون يسجلون ويتحققون؛ الموارد البشرية تفعّل وتراقب |
| **سير العمل المعتاد** | التسجيل (3 التقاطات) → التحقق عند تسجيل الحضور → إعادة المحاولة أو إعادة التسجيل عند الفشل |

**القدرات الرئيسية:**

- [تسجيل التعرف على الوجه](./FEATURES.md#geofencing-and-work-type-location-policies) للموظف (ثلاث التقاطات ناجحة كحد أدنى)
- التحقق عند تسجيل الحضور عبر كاميرا المتصفح
- طلبات إعادة تسجيل التعرف على الوجه عند فشل التحقق
- تركيز على الخصوصية: يخزّن قوالب وجه رياضية، وليس صور التسجيل

**الفوائد:** يقلّل تسجيل الحضور بالنيابة؛ متاح في جميع الباقات بما فيها Trial؛ فرض اختياري.

**القيود:** يتطلب كاميرا وإضاءة كافية؛ يتحكم بتسجيل الحضور فقط.

تفاصيل إضافية: [الميزات — Face Check-In](./FEATURES.md#face-check-in). السياسة: [سياسات Face Check-In](./POLICIES.md#face-check-in).

**توفر الباقة:** All plans.

### Activity Tracking

![وكيل سطح المكتب يراقب النشاط؛ المديرون يراجعون ويصنّفون مقاطع الخمول](../../product/assets/activity-monitoring.png)

**الغرض:** مراقبة الحضور على سطح المكتب عبر تطبيق Social HR Desktop.

> **نظرة سريعة:** النبضات · مقاطع الخمول/المراجعة · لقطات شاشة اختيارية · تصنيف المدير

| | |
|---|---|
| **من يستخدمها** | الموظفون يشغّلون تطبيق سطح المكتب؛ المديرون يراجعون؛ الموارد البشرية تُعدّ السياسات |
| **سير العمل المعتاد** | تثبيت التطبيق → تسجيل الحضور → نبضات → المدير يصنّف مقاطع المراجعة → تسجيل الانصراف |

**القدرات الرئيسية:**

- [النبضات](./FEATURES.md#geofencing-and-work-type-location-policies) تُبلّغ عن لوحة المفاتيح والفأرة ووقت الخمول والنافذة النشطة
- مقاطع النشاط: نشط، خمول، ويتطلب مراجعة
- لقطات شاشة دورية اختيارية مع احتفاظ قابل للتخصيص
- [درجة الإنتاجية](./FEATURES.md#geofencing-and-work-type-location-policies) (إعلامية — ليست في قسائم الراتب)
- تصنيف المدير: مدفوع، غير مدفوع، أو اجتماع

> **مهم:** مراقبة النشاط **لا** تغيّر [Attendance](./MODULES.md#attendance) أو [Payroll](./MODULES.md#payroll) تلقائياً. راجع [قرارات التصميم — الحضور والانصراف يحدّد الأجر](./DESIGN_DECISIONS.md#attendance-drives-pay-activity-provides-oversight).

تفاصيل إضافية: [الميزات — Activity Tracking](./FEATURES.md#activity-tracking-desktop-monitoring). السياسة: [سياسات Activity Tracking](./POLICIES.md#activity-tracking).

**توفر الباقة:** [Standard، Enterprise](./PLANS.md#standard).

## إعدادات النظام (عابرة للوحدات)

ليست وحدة في الشريط الجانبي، لكنها إعدادات أساسية تؤثر على وحدات متعددة:

| مجال الإعداد | يؤثر على |
|--------------|----------|
| العطل الرسمية | حسابات [Leave](./MODULES.md#leave)، [Attendance](./MODULES.md#attendance) |
| إجازات الشركة | أنماط عدم العمل على مستوى المؤسسة |
| تقييد الإجازات | قواعد نطاق التاريخ التي تحظر طلبات الإجازة |
| الموافقات المتعددة | سلاسل موافقة متعددة الخطوات للإجازات وطلبات أخرى |
| قوالب البريد والأتمتة | إشعارات البريد عبر الوحدات |

يُمكن الوصول إليها عبر قسم إعدادات النظام في الشريط الجانبي.
